Improve your HR recruitment processes using Odoo integration with Djinni

Description

Integrate Odoo with Djinni.co HR service to improve your recruitment processes. Using this solution, you can publish vacancies, edit, activate/deactivate, and delete them. All vacancy data and job candidate information is uploaded to Odoo, and can be used by your recruitment managers.

Hiring in Odoo can be enhanced with Odoo solutions from Garazd Creation, such as integration with Robota.UA and Work.UA.

Configuration
Getting an API key
Before settings on the Odoo side, obtain the API key in your Djinni account. Open the "API" tab click to Get API key button, then copy the key.
Settings in Odoo
The next step is configuration in Odoo, go to the "Recruitment" - "Configuration" - "Djinni" - "Acccounts" menu and create a new account. You can select one of the two available authorization types:
  • Login - your Djinni login and password are used in this case.
  • API Key - you need to specify your Djinni e-mail address and API key created in the previous step.
To log Djinni integration requests to Odoo log, activate the Debug Mode option.
Completing with settings, click to Synchronization to perform the initial synchronization with Djinni.co service.
Synchronization

Further synchronization will be performed automatically using cron tasks:

  • Job vacancy details and job applications are synced every 30 minutes. This period can be adjusted by system administrators.
  • Other cron task syncs the common catalogs once a day.
Extra Operations
Posting a new vacancy from Odoo

You can post a new vacancy from Odoo, to perfom that, create a new job or use some job that is not linked to Djinni. Choose the "Sync with Djinni" action from the Actions menu.

In the wizard, fill in all required options for this vacancy.

Add your vacancy description using HTML markup.

And on the final "Quiz" tab, add your questions for vacancy candidates if it's required.

After filling in all the required information, click on the Create button to add the vacancy on the Djinni side.

Editing a Djinni vacancy

You can use the same action, Sync with Djinni, to edit or change the job options on the Djinni side for the already linked vacancies.

After making changes, click on the Sync button to synchronize.

Vacancy deactivation
The following actions should be approved on the Settings. To allow them, go to the "Recruitment" - "Configuration" - "Settings" menu, and in the "UA service integration" section, activate the required options.
Unpublish vacancy

To deactivate a vacancy on Djinni side, just archive the job in Odoo.

Vacancy removing

If you delete a job in Odoo, the linked Djinni vacancy will be deleted as well.
